# 🔒 Python SSL Certificate Expiration Monitor

A lightweight, high-performance Python monitoring script to check SSL/TLS expiration dates, certificate issuers, and validation status across multiple domains.

Powered by the **[SSL Certificate Inspector API](https://rapidapi.com/Huebercool/api/ssl-certificate-inspector)** on RapidAPI.

---

## 🚀 Quickstart

### 1. Install Dependencies
```bash
pip install -r requirements.txt
export RAPIDAPI_KEY="your_actual_rapidapi_key_here"
python risk_scanner.py

DOS
set RAPIDAPI_KEY="your_actual_rapidapi_key_here"
python risk_scanner.py

Shell
$env:RAPIDAPI_KEY="your_actual_rapidapi_key_here"
python risk_scanner.py
